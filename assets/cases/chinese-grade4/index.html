杨华德 shuài lǐng (_________) 专家组... 经过不懈的 nǔ lì (_________)， 取得 fēng shuò (_________) 的成果...

2. 选择正确读音：

着力 [zháo zhuó]

屡次 [lǚ lǔ]

不懈 [jiě xiè]

📖 老师敲黑板

✍️ 易错字书写：

  • 一丝不苟：“苟”不要写成“荀”，意思是连最细微的地方也不马虎。
  • 艰巨：“艰”右边是“艮”，不要少一笔。
  • 率领：“率”字中间是点、横、撇、折、点，不要漏写点。
  • 丰硕：“硕”右边是“页”，表示果实很大。

🔊 易错读音辨析：

  • 着力 (zhuó)：表示用力、下功夫。zháo通常用于“着火”。
  • 屡次 (lǚ)：注意声调，不要读成 lǔ。
  • 不懈 (xiè)：不要读成 jiě（解），不懈意味着不松懈。
3. 人物品质： 正确答案是 C. 坚持不懈。 解析：文中提到了“50年”、“十年如一日”、“百折不回”、“11年辛勤耕耘”，这些关键词都指向了“坚持”。

第二部分：课内阅读《猫》

错题率: ⭐⭐⭐⭐
10分
原文片段：...说它老实吧，它的确有时候很乖...说它贪玩吧，的确是啊...可是，它听到老鼠的一点儿响动，又是多么尽职...

1. 填空题 (3分)

选文写出了猫既 又贪玩，既贪玩又 的特点，让我们充分感受到猫的性格实在 。

2. 判断正误 (3分)

  • 观点1 我觉得作者不喜欢猫。从...可以看出作者在责怪、批评猫的贪玩。 ( )
  • 观点2 作者虽然在写猫的贪玩...反而像是把猫当作既淘气又可爱的孩子... ( )
  • 观点3 作者用“说...吧...的确...可是...”这样的句式...实则表达了对猫的喜爱。 ( )

🔍 深度解析

第1题：找关键词

答案：既 老实 又贪玩，既贪玩又 尽职。性格实在 古怪。

💡 解题技巧： 答案就在文章里！仔细读第一句话“猫的性格实在有些古怪”，这是中心句。后面的内容分别对应了“老实”、“贪玩”、“尽职”这三个方面。

第2题：体会情感

× 观点1：老舍先生非常爱猫，这里的“责怪”其实是“明贬实爱”（表面批评，实际喜欢）。就像妈妈说你“小调皮”一样。
√ 观点2：把猫当做孩子，充满了爱意。
√ 观点3：这种转折句式突出了猫性格的多变和有趣。

第三部分：口语交际 - 转述新闻

错题率: ⭐⭐⭐
5分
来源：新闻联播

新闻片段：

“《2024中国诗词大会总决赛》将于今晚八点在央视综合频道播出。六强选手将通过情景共答题、飞花令、画中有诗等丰富的题型比拼...”

📞 打电话给小文：

小文，我刚刚在《》看到了这一则消息： 六强选手将通过 等题型进行大比拼...

📡 信息提取小侦探

口语交际的核心是“听得清，说得准”。我们需要从新闻中提取关键信息（Who, Where, What）。

  • 第1空

    答案：新闻联播

    注意看题目来源提示“来源：《新闻联播》”，很多同学漏看了这个小细节！

  • 第2空

    答案：情景共答题、飞花令、画中有诗

    题目要求填“题型”。直接从文中找到“通过...等丰富的题型”这句话，把中间的内容抄下来即可。
